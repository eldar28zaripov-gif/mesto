# Mesto

Интерактивный проект Mesto с подключением к API, валидацией форм и возможностью работы с карточками.

## Команды

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run deploy`

## Публикация

- https://eldar28zaripov-gif.github.io/mesto/

## Структура

- `index.html` — основная страница проекта
- `src/scripts/index.js` — входной скрипт приложения
- `src/scripts/components/` — модульные компоненты API, карточек, модальных окон и валидации
- `pages/index.css` — главный файл стилей
- `blocks/` — CSS-блоки проекта
- `vendor/` — сторонние стили (normalize, шрифты)
- `images/` — медиа-файлы, используемые в приложении

## Публикация

Проект публикуется на GitHub Pages командой:

- `npm run deploy`
